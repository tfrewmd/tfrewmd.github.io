Privacy Policy

Last updated: September 28, 2026

Personal Assistant Bot (the "app") is a Telegram bot built for personal use only. It isn't offered to the public. Only a small allowlist of pre-approved Telegram chats can use it, and the app ignores messages from any other chat without storing them.

Data the app collects

  • Telegram messages. The app receives the text, voice messages, photos and documents sent to it by allowlisted chats. It processes them to work out what to do and how to reply. It doesn't keep a message history.
  • Tasks. Tasks and reminders created from messages are stored in the app's database, along with their due dates, status and the Telegram chat ID they belong to.
  • Google Calendar (optional). If a user connects Google Calendar through Google OAuth, the app requests only the https://www.googleapis.com/auth/calendar.events scope. It uses this to read events on the user's primary calendar, for daily summaries, reminders before events and answering questions about the schedule. It creates or deletes events only when the user explicitly asks. The OAuth refresh token is stored encrypted (AES-256-GCM). Event contents aren't stored or logged. The app keeps only the event IDs and start times needed to avoid sending the same reminder twice.

How data is processed

To understand messages, the app sends message content to third-party AI services acting as processors:

  • Anthropic (Claude) for text, photos, documents, and calendar events when matching a request to an event.
  • OpenAI for voice message transcription and spoken replies.

The app runs on Railway, a cloud hosting provider. Data is used only to provide the assistant's features to the allowlisted user. It is never sold, shared for advertising, or used for any other purpose.

Google user data

The app's use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. Google Calendar data isn't used to train AI models, and it isn't transferred to anyone except as described above to provide the app's features.

Deleting data and revoking access

  • Send /disconnect to the bot. This revokes the app's Google access and deletes the stored token.
  • Google access can also be removed at any time from Google Account permissions.
  • To have stored tasks deleted, contact the app owner.

Contact

For questions about this policy, contact the app owner through GitHub.
