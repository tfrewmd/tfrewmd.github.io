Personal Assistant Bot

A private Telegram assistant for tasks, reminders and calendar.

Personal Assistant Bot is a Telegram bot built for personal use. It isn't a public service, and only a small allowlist of pre-approved Telegram chats can use it.

What it does

  • Keeps a task list from plain-language messages, like "remind me to call the dentist tomorrow at 3pm".
  • Understands voice messages, photos and PDF documents.
  • Sends check-ins at 8am, 2pm and 8pm that summarize open tasks.
  • Optionally connects to Google Calendar. It can list today's events, add or delete events when explicitly asked, and send a reminder 30 minutes before an event.

Google Calendar access

Calendar access is opt-in. The user connects with the /connect command, which starts Google's standard sign-in. The bot asks only for permission to view and edit calendar events. It never asks for calendar settings or sharing. Access can be revoked at any time with /disconnect or from the user's Google Account permissions.
